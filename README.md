# HGB Welcome Bot

Bot Discord chào mừng & tạm biệt thành viên với embed đẹp.

## ✨ Tính năng

- 👋 Welcome member mới với embed + banner + thumbnail
- 🚪 Goodbye member rời server
- 🎨 Tuỳ chỉnh title, description, banner, thumbnail, footer
- 🔐 Auto-role cho member mới
- 💾 Lưu config bằng SQLite
